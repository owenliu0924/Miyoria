# Miyoria 生圖抽卡企劃

2026-11-12 起草(owner)。2026-11-14 收進 repo;V5 怎麼接它見 [v5-architecture.md](v5-architecture.md) 和 [v5-play.md](v5-play.md)。

## 一句話結論

卡分兩種。**每日卡**是她每天給你的關係卡,眼鏡、手上的東西、背景這些部件不再另外花錢抽,而是發卡時隨機配上,不能指定,只能收藏、不能交易。**生圖卡**是另外一個卡池,比較貴,背景和人物都是生成的,排版也和每日卡不一樣:每一抽都是一張世界上只有一張的卡,卡池抽的是「主題」(公開機率),圖是 Krea 2 Turbo + 她的 LoRA 透過 ComfyUI 生的,她看圖後親手寫卡面文字。為了不讓人等、不和 TTS / 唱歌搶顯卡,大部分卡先在離峰時段生好放進「底片庫」,抽到時才正式發給你,用過的圖永不重複;只有最高稀有度會現場為你生成。下面除了「兩種卡」一節,講的都是生圖卡。

取代舊企劃(《經濟與抽卡 3.0》)的抽卡部分;舊企劃中的「生圖系統(ComfyUI 模組)」和「Krea 2」兩節照樣使用,這份是建在它們上面的玩法。底線不變:沒有真錢、機率公開、稀有度不是好感。

## 兩種卡

|  | 每日卡 | 生圖卡 |
| --- | --- | --- |
| 怎麼拿到 | 她每天給的關係卡(一天最多 5 張),不用另外抽 | 花魚幣抽的獨立卡池 |
| 隨機的東西 | 眼鏡、手上的東西、背景等部件,發卡時照公開機率隨機配上 | 主題、場景、構圖、姿勢,整張圖生成 |
| 能不能指定 | 不能(部件不能花錢選) | 只能選卡池,不能選圖 |
| 圖 | 她的立繪 + 部件,固定的每日卡排版 | 背景和人物都是 AI 生成,另一套排版(全圖、卡面文字疊在圖上) |
| 交易 | 不能,只能收藏 | 見下面「贈送 / 交易」 |
| 價格 | 免費(關係的一部分) | 比較貴,每日上限較低 |
| 用顯卡 | 不用 | 用(離峰補底片) |

- 現在的「抽收藏」(`collection_series`,30 魚幣一抽)拿掉,裡面的眼鏡、手上的東西、背景改成每日卡的部件。已經抽到的收藏留在圖鑑裡。
- 部件的稀有度和機率照樣公開,圖鑑照樣收集部件(集滿一個系列給稱號)。
- 兩種卡的圖鑑、保底各自計算,彼此不換算。

上半部在離峰時段一直補底片,自動檢查沒過的重生;抽卡當下只要有底片,只等她寫卡面的幾秒。沒有底片或抽到 SSR「和你」時才現場生成。

## 卡池、稀有度與生成品質

一抽先抽稀有度,再從那個稀有度的主題裡抽一個,最後拿一張那個主題的圖。稀有度決定主題有多特別、生圖花多少力氣,不影響她對你的感覺。

| 稀有度 | 機率 | 主題例子 | 怎麼生 |
| --- | --- | --- | --- |
| N | 70% | 日常:在房間發呆、吃白飯、睡午覺 | Turbo 8 步、1K,半身或 Q 版 |
| R | 22% | 外出:便利商店、下雨的公車站、海邊 | Turbo + 專屬場景 prompt,全身 |
| SR | 7% | 特別服裝、節日、她這週發生的事 | Medium / RAW 高步數,2K 放大,複雜構圖 |
| SSR | 1% | **「和你」**:由你和她的關係生成的場景(你們常聊的東西、一起玩過的遊戲) | 現場為你生,加一張覺醒圖 + 她的一句語音 |

- **主題池**:每個主題是一個 prompt 模板(場景、服裝、動作、光線的範圍),不是一張圖。同一個主題每次生出來都不一樣(seed、姿勢、表情、角度都會變)。
- **常駐池 + 每週限定池**:限定池的主題由她從本週的生活提,你在面板核准模板(審的是模板,不是每張圖)。
- **「和你」的隱私**:SSR 的場景只用公開的事(你們在公開頻道聊過的話題、玩過的遊戲),不用私訊和她對你的記憶內容;卡上不出現你的臉。
- **保底**:30 抽必出 SR 以上;限定池 80 抽必出本期 SR 主題,計數跨週延續。
- **價格**:生圖卡池比一般卡池貴,草案一抽 150 魚幣、十連 1350,一天最多 20 抽(上限主要是為了顯卡產能,見「產能與成本」)。實際倍數看魚幣的經濟再調。

## 底片庫:先生好,抽到才「沖洗」

現場生圖有三個問題:要等、會和 TTS / 唱歌搶顯卡、生壞了來不及擋。所以 N / R / SR 都從底片庫拿:

- **底片**:每個主題保持一個庫存量(例如 N 30 張、R 15 張、SR 8 張),低於門檻就排 batch job 補貨,只在離峰或她沒在唱歌 / 開台時跑。
- **一張只發一次**:抽到時把那張底片綁到你的卡(序號、seed、主題),從庫存移除,永遠不會發給別人。所以仍然是「世界上唯一一張」。
- **沖洗動畫**:抽卡時不是直接翻牌,而是一張底片慢慢顯影,同時她看圖寫卡面文字(幾秒),實際上是在等 LLM 而不是等生圖。
- **庫存不夠時**:這一抽變成「未沖洗的底片」,先扣錢、先公布稀有度和主題,圖生好後私訊通知;一天內生不出來就退錢。這把等待變成一個「期待」而不是卡住。
- **SSR 「和你」**:因為內容和你有關,一定現場生,一律走「未沖洗」流程,排 `interactive` 優先,但她在唱歌時仍然等。

## 品質與安全:機器先篩,你抽查

生圖量大了你不可能張張看,所以每張進底片庫前要過自動檢查,沒過的重生(同一個主題最多重試 3 次):

| 檢查 | 抓什麼 | 怎麼做 |
| --- | --- | --- |
| 像不像她 | 臉跑掉、髮色不對 | 拿圖和她的參考圖算圖像 embedding 相似度,低於門檻就丟 |
| 壞圖 | 多手指、崩臉、糊圖 | 臉 / 手偵測 + 美感分數,低分丟掉 |
| 不該有的內容 | 暴露、血腥 | NSFW 分類器;主題模板本身也走現有的審查和主人規則 |
| 她自己看 | 圖和主題不對、她覺得怪 | 她用看圖能力寫卡面時,可以回「這張不像我」,就不發 |

- **你審的是主題模板**,每個新主題上架前看一組樣本(例如 12 張)。之後每天面板隨機抽幾張底片給你看,不用全看。
- **SSR 和「和你」的圖**,前一個月全部經你看過才沖洗,之後看自動檢查的表現再決定放不放。
- **檢舉**:卡片頁有「這張有問題」,收到就先隱藏、退錢、進你的待辦。
- **標示**:卡片頁寫明「圖由 AI 生成」。

## 收集、重複與她的參與

每張圖都不一樣,所以「重複」只會是同一個主題,不會是同一張圖。收集的單位是主題,展示的單位是你最喜歡的那張。

- **圖鑑**:每個主題一格,抽到就亮;同一主題有多張時,你挑一張當「封面」。集滿一個系列(例如「夏天」的五個主題)給稱號和卡框。
- **同主題 3 張 → 覺醒**:合成時拿你挑的那張當參考,用更高品質重繪出「覺醒版」(img2img、放大、加光效),另兩張消失。重複有用途,也是卡的回收口。
- **分解**:不想留的卡可以分解成鱗片,鱗片換「指定主題一抽」(你選主題,不選圖)。
- **她寫卡面**:每張卡她看圖寫一句話(「這天在便利商店買了太多飯糰了…」),所以同主題的卡文字也不一樣。SSR 加一句她的 TTS 語音。
- **她記得**:抽到 SR 以上、誰覺醒了哪張,進她工作脈絡的 `gacha` 桶;你可以「拿卡給她看」,她看圖回應,一天一次。
- **全服相簿**:面板和網頁現場有一面「大家抽到的她」的牆(只放本人同意公開的),不排名。
- **贈送 / 交易**:保留舊規則,一般卡可以送,SSR「和你」不能送(那是你們的事),不能賣。

## 產能與成本估算

本機跑的話主要成本是顯卡時間,不是錢。下面是假設,上線前要在你的顯卡上實測一張 Turbo 1K 的秒數再改:

| 項目 | 假設 |
| --- | --- |
| 每天抽卡的人 | 30 人 |
| 每人每天抽 | 5 抽 |
| 每天要發的卡 | 150 張 |
| 自動檢查淘汰率 | 30%,所以每天大約要生 215 張 |
| 每張花的時間 | 待測(如果是 10 秒,一天大約 36 分鐘顯卡時間) |

- 離峰時段(例如 02:00–09:00)有 7 小時,就算一張 60 秒也跑得完,所以本機應該夠;真正的限制是 VRAM(Turbo fp8 社群估計要 16GB 起)。
- 一天 20 抽的上限和底片庫存量一起決定;底片快用完時可以自動把上限調低,而不是讓人抽到未沖洗的底片。
- 用雲端的話,Krea API Medium 一張 US$0.030,215 張一天大約 US$6.5;但 API 要用 Krea 平台上訓練的 style,不是你的 ComfyUI workflow。建議只當備援。
- 重新訓練 LoRA(例如加新服裝)用 fal 一次大約 US$3 / 1000 步,或本機訓練。

價格來源:[Krea 2 API overview](https://www.krea.ai/docs/developers/krea-2/overview)、[fal Krea 2 Trainer](https://fal.ai/models/fal-ai/krea-2-trainer);VRAM 來自第三方 [DreamPixelForge](https://www.dreampixelforge.com/blog/krea-2)。

## 分階段與要決定的事

1. **生圖底座**:`packages/imagegen` 接 ComfyUI、`image_jobs`、訓練她的 Krea 2 LoRA、一個 N 主題的 workflow;實測每張秒數和 VRAM。
2. **底片庫 + 自動檢查**:補貨排程、相似度 / 壞圖 / NSFW 三道檢查、面板抽查和主題樣本審核。
3. **生圖卡上線**:主題池作為獨立的、比較貴的卡池,另一套卡面排版;同時把 `collection_series` 的抽收藏改成每日卡隨機配部件。沖洗動畫,她寫卡面,圖鑑和分解。
4. **限定池、覺醒、SSR「和你」**:她提主題、現場生成、語音。

**要你決定的事**

1. ComfyUI 跑在哪台、顯卡有多少 VRAM,是不是和 TTS / 唱歌同一張。
2. DeepSeek-chan 模型作者允不允許用她的外觀訓練 LoRA(這件不確定,整個企劃就要改成委託繪師)。
3. SSR「和你」要不要做,以及能用哪些關於你們的資料。
4. 每日卡的部件機率,以及已經抽到的舊收藏怎麼算(留在圖鑑,或補償魚幣)。
5. 生圖卡的價格和每日上限(草案一抽 150 魚幣、一天 20 抽)。
