# 深海交易所

> 2026-11-14 規劃,沒有實作。它是 [v5-play.md](v5-play.md) §4.4 的完整設計。owner 的要求:模擬的公司、代號像股票、有偶發事件(包含下市)、盡量真實。規則參考台股的習慣(漲跌停、除息、抽籤、注意股和處置股),數字都是草案。

## 0. 結論

1. **八家假公司**,價格由程式模擬,新聞由她寫。她是財經主播,不是莊家:她看不到隱藏的數字,也不下場買賣。
2. **股市不印錢,這是硬規則**。買股票的錢進一個金庫,賣股票的錢從金庫出。所有玩家合起來,從股市拿走的永遠不會超過放進去的。手續費和交易稅另外收,直接燒掉,這是回收。
3. **資金水位**把價格和金庫綁在一起:股價跑在資金前面時,大盤會被往下拉。這也是真的股市的樣子:行情跟著資金走。
4. **事件**有例行的(財報、除息、股東會)、偶發的(醜聞、併購傳聞、增資)、全市場的(升降息、黑天鵝、熔斷)和監管的(注意股、處置股、下市)。種類和大小由程式抽,她只寫字。
5. 上線前先跑模擬,再做兩週不能下單的紙上交易。

## 1. 底線

- 沒有真錢。魚幣只能賺,不能買。
- 規則、手續費、漲跌幅、金庫餘額、每週燒掉多少,全部公開。
- 模型不碰數字:價格、事件、成交都是程式算的,可以用當天的種子重算。
- 不能借錢、不能放空。最多賠光自己放進去的。
- 花在股市的錢買不到羈絆。

### 2.2 開盤時間

- 每天 12:00 到 23:00(台北時間),每個整點撮合一次,一天 12 盤。23:00 那一盤是收盤價。
- 開盤的參考價是前一天的收盤價。**單日漲跌幅 ±10%**,到了就是漲停或跌停。
- 漲停時交易所不賣(買單排著,可能買不到);跌停時交易所不買(賣單排著,可能賣不掉)。
- 大盤單日跌超過 7% 就熔斷,當天不再撮合。

### 2.3 三大法人(只有顯示)

行情圖上有「外資」「投信」「自營商」今天買超或賣超多少。這些數字是從模擬的大盤和類股因子換算出來的,給她講評用,也給人猜;它們不是真的玩家,不動金庫。

## 3. 金庫和資金水位

這一節是整個設計不會讓魚幣變多的原因。

- **金庫**:玩家買進時付的成交金額進金庫,賣出時拿的成交金額從金庫出。除此之外,金庫只有三種支出:配息(§4.2)、下市的清算(§4.4)、每週的銷毀。它沒有別的收入來源,程式不會憑空往裡面放錢。
- **手續費和交易稅不進金庫**,收了就燒掉。
- **資金水位 = 金庫 ÷ 所有人持股的市值**。水位是 1 表示照現在的價格,金庫剛好付得起所有人賣光。
  - 水位低於 1:股價跑在資金前面,大盤每一盤都被往下拉一點,離 1 越遠拉得越用力。
  - 水位高於 1:錢比股票多,大盤被往上推。
  - 水位公開。看得懂的人會在水位低時先跑,這也是真的。
- **金庫付不出來時,那筆賣單不成交**,留到下一盤。這是流動性不足,不是系統出錯。
- 所以不管價格怎麼跑,**所有玩家合起來能拿走的,最多就是他們放進去的**。個別的人賺的,是別人賠的。

一次性的玩具模擬(35 個隨機行為的玩家、八檔股票、180 天、40 次,不是真實玩家的行為):

| | 有資金水位 | 沒有 |
|---|---|---|
| 水位的中位數 | 約 1.00 | 約 0.98 |
| 水位最低到過 | 0.80 到 0.94 | 最差的一次到 0(金庫付不出任何錢) |
| 180 天裡賣不掉的次數(含跌停) | 13 到 87 次 | 最多 341 次 |
| 大盤的單日波動 | 約 2.3% | 約 2.4% |
| 燒掉的 ÷ 成交金額 | 約 3% | 約 3% |

正式的模擬要用上線的那一套價格引擎重做(§9 的 E0)。

## 4. 事件

每一種事件的出現、方向、大小都由程式用當天的種子從牌組裡抽,有各自的冷卻時間。她拿到的是「哪家公司、哪種事件、利多還是利空、大概多大」,寫成一句標題和兩三句內文。

### 4.1 例行的

| 事件 | 多久一次 | 效果 |
|---|---|---|
| 週財報 | 每週日收盤後 | 每家公布營收和 EPS,和她週五公布的「預估」比:優於預期漲、不如預期跌,當週波動放大 |
| 她的預估和評等 | 每週五 | 她依公開的新聞給每家「買進 / 持有 / 賣出」和一句理由。她會錯,而且她自己知道 |
| 除息 | 配息的公司每四週一次 | 見 §4.2 |
| 股東會 | 每家每季一次 | 股東會當天持有至少一股的人拿到紀念品:一個只有股東拿得到的每日卡部件或稱號 |

### 4.2 配息

- RICE、NAPS 固定配息,其他公司賺錢的那一季才配。殖利率每季 1% 到 3%。
- 錢從金庫付給持有人,**除息當天股價扣掉同樣的金額**,和真的一樣。所以配息不是多出來的錢,是把股價的一部分變成現金。
- 金庫水位低於 0.9 時所有公司停止配息。

### 4.3 偶發的

| 事件 | 頻率(每家) | 效果 | 備註 |
|---|---|---|---|
| 新產品、大訂單 | 一週 0 到 2 次 | ±1% 到 4% | 最常見 |
| 高層異動 | 一個月約 1 次 | ±1% 到 3% | |
| 訴訟、資安事件、醜聞 | 一季約 1 次 | −3% 到 −10%,可能跌停 | 會讓公司進注意股 |
| 併購傳聞 | 一季約 1 次 | 先漲 3% 到 8%,幾天後證實(再漲)或否認(跌回去) | 傳聞有四成是真的。她會用「聽說」來報 |
| 現金增資 | 體質變差時 | 新股用折價抽籤賣出,原股東被稀釋,股價跌 | 新的錢進金庫 |
| 股票分割、減資 | 股價高於 300 或低於 15 | 只改股數和股價,市值不變 | |
| 庫藏股 | 股價連跌時偶爾 | 小幅支撐 | |

### 4.4 全市場和監管

| 事件 | 頻率 | 效果 |
|---|---|---|
| 升息、降息 | 每四週一次 | 她是魚幣央行的總裁。魚幣總量長得太快就升息(大盤跌),太慢就降息。決定由經濟健康表的數字算出來,她負責宣布 |
| 類股輪動 | 隨時 | 四個類股各有自己的起伏 |
| 多頭、盤整、空頭 | 幾週換一次 | 大盤的長期氣氛 |
| 黑天鵝 | 一季最多一次 | 全市場大跌,可能全面跌停,之後進入空頭 |
| 熔斷 | 大盤單日 −7% | 當天停止撮合 |

**注意股 → 處置股 → 全額交割 → 下市**:

1. **注意股**:三天內累計漲跌超過 25%,或出了醜聞。只是標記,她會提醒。
2. **處置股**:連續三次被列注意。五天內每三盤才撮合一次,單筆買進上限減半。
3. **全額交割**:公司的體質掉到很差(淨值為負)。只能賣、不能新買進。她每天報一次「警示」。
4. **下市**:全額交割滿三天還沒改善。公告後再三天才生效,這三天可以賣(賣得掉的話)。下市時持股以最後收盤價的一成清算,錢從金庫付。那家公司消失後金庫多出來的部分,一半燒掉,一半留著(水位上升,其他股票受益)。

只有 §2.1 標「會」的公司走得到第 3、4 步。

### 4.5 新股上市

- 每季最多一家。公司由 owner 定,或由拍賣得標的人提名(owner 核可名字)。
- **抽籤申購**,照台股的做法:申購期三天,每人最多申購一個單位,先扣款;抽中的人用承銷價拿到股票,沒中的全額退回(申購手續費 5 魚幣不退,燒掉)。承銷價訂得比估值低一點,所以中籤通常小賺。
- 申購的錢進金庫。上市頭五天沒有漲跌幅限制。

## 5. 價格怎麼算

每一盤、每家公司:

```
這一盤的漲跌 = 大盤因子 × 這家的敏感度
             + 類股因子
             + 這家自己的雜訊
             + 往「體質」拉回的力
             + 這一盤的新聞
             + 這一盤玩家淨買進造成的價格衝擊
```

- **大盤因子** = 多空氣氛 + 隨機 + 資金水位的拉力(§3)。
- **體質**是每家公司看不到的合理價,自己慢慢隨機漂移,沒有長期方向。財報上的營收和 EPS 是從它換算出來給人看的。
- **價格衝擊**:大家一起買,價格當場被買上去;一起賣就被賣下來。衝擊的大小看這家公司的流通量,小公司比較容易被炒。因為買和賣都有衝擊,自己拉高再賣給自己是賠的。
- 算出來之後套上漲跌停。
- 整個模型校準成「不算手續費時,長期持有的期望報酬是零」。算上手續費,整體是賠的。

## 6. 交易規則

| 項目 | 規則 |
|---|---|
| 開戶 | 帳號連結滿 7 天,而且羈絆到「認識」以上(擋小號) |
| 單位 | 一股起,可以買零股;股價到小數兩位 |
| 委託 | 市價單(下一盤成交)和限價單(當日有效或五日有效) |
| 成交對象 | 交易所。玩家之間不直接成交 |
| T+1 | 今天買的,明天才能賣 |
| 手續費 | 買、賣各 1.5%,燒掉 |
| 交易稅 | 賣出時 3%,燒掉 |
| 持有上限 | 每家公司成本 500 魚幣,全部合計 2,000 |
| 不行的事 | 借錢買、放空、轉讓股票給別人 |
| 下單頻率 | 每人每盤最多 5 筆 |
| 誰不能交易 | 看得到種子和隱藏數字的人:owner、管理員 |

一買一賣的成本合計 6%。

## 7. 她和看得到的地方

- **她是主播**:每天開盤一句、收盤發一張行情圖加評語、每週五預估、每週日財報講評。她會吐槽自己老家的股價,也會在升息時說「不是我要升的」。
- **她不知道內情**:她拿到的只有公開的價格和新聞,和玩家一樣。她的評等是意見。
- **她不下場**:她沒有持股。
- **Discord**:一個 `/market` 面板,用按鈕和表單下單、看庫存、看新聞;不做一堆子指令。行情、個股走勢、對帳單、交易量表都是算出來的圖([v5-play.md](v5-play.md) §9)。
- **網頁「公開資訊觀測站」**:每家公司一頁(簡介、走勢、新聞、歷次財報和配息、是不是注意股或處置股);規則和費率;金庫餘額、資金水位、本週燒掉多少。
- **交易量表**:這一週誰買賣的金額最多。不排賺賠,不排身家。
- **股東會紀念品**進每日卡的部件圖鑑。

## 8. 會被怎麼玩壞,怎麼擋

| 玩法 | 擋的方式 |
|---|---|
| 開小號洗量、互倒 | 成交對象是交易所,互倒沒有意義;開戶有門檻;交易量表對同一個人連結的帳號合併計算 |
| 幾個人約好一起拉高 | 買進有價格衝擊,賣出也有;T+1;每家有持有上限。先買的賺後買的錢,合起來仍然是賠手續費 |
| 利用真事(瘋狂餵她來拉 RICE) | 真事一天最多 ±3%,而餵食本身在燒魚幣 |
| 內線 | 看得到種子的人不能交易;新聞對所有人同時公布;下一盤才成交 |
| 寫程式下單 | 每盤筆數上限;價格只在整點變,搶快沒有用 |
| 擠兌 | 跌停時交易所不買;金庫付不出來就不成交;水位低時大盤本來就在跌。這是設計的一部分 |

owner 有一個總開關可以暫停整個市場。

## 11. 還沒定的

1. 開戶的門檻(草案:連結滿 7 天、羈絆到「認識」)。
2. 持有上限要不要隨羈絆或開戶時間放寬。
3. 以後要不要有指數基金(買 FISH)。草案沒有。
4. 放空以後要不要開。草案不開:它讓人可能賠超過本金,也讓金庫的帳變複雜。
