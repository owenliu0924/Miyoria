## 0. 十個結論

1. **Harness 讓模型看起來聰明,靠的是五樣東西**:夠長的迴圈、留得住的逐字稿(含工具呼叫)、找得到的工具、子代理、沒人事後改它的輸出。DeepSeek Harness 還多一條:模型看到的每一樣東西都能從紀錄重建。
2. **「什麼都能做」來自 Gateway 加外掛**:一個行程擁有所有平台連線和狀態,平台是外掛,session 鍵有固定文法,核心只有一個送訊息的工具。
3. **主動搭話的共識**:先過不花 token 的閘門,再把「動機」交給模型並允許它不說,沒人回就拉長間隔。
4. **陪伴感排名**:中文市集裝最多的是貼圖、主動搭話、記憶、群聊讀空氣;遊戲、抽卡、純好感度外掛少兩個數量級。
5. **好感度用「模型在回覆尾巴寫標籤」最常見,也最常壞**(模型忘記寫)。比較穩的做法是模型只分類事件或提出變動,數字由程式限制。
6. **沒有人把經濟或抽卡和關係綁在一起**。這塊是空的。
7. **卡片 bot 的共同循環**:限時的抽或掉落 → 搶 → 每張卡是獨立的一張 → 抽完還有事做。停在「抽到了」的都會冷掉。
8. **多台電腦的共同形狀**:一次性的加入代碼換成每台的金鑰、對外撥入、宣告能力並另外核可、心跳、依能力分派、報到時檢查版本。
9. **AI VTuber 的遊戲接法**:穩定的 JSON-schema 動作、立刻回的驗證結果、帶優先級的強制選擇;即時的反射留在遊戲那一側,模型只下意圖。
10. **不要照抄的**:對外開放的 gateway、技能市集、把核可提示當安全邊界、預設寬鬆的權限。

## 1. DeepSeek Harness 和「大肥魚」

**它是什麼** [文]:DeepSeek 開源的 agent harness([deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness),MIT,developer preview)。蓋在 Cordis 上,模型轉接、工具登記、session 紀錄、agent 迴圈全部是外掛,登記可以反向解除。可以跑成 Web UI、Electron 桌面版(`desktop` profile)、`headless`、`sdk`(JSON-RPC)、`acp`。

- **回合**:`turn/start` → 認領收件匣 → 組提示詞 → `agent/pre-step`(可接受、改寫、拒絕)→ 模型 → 工具(執行前 / 執行 / 執行後)→ `turn/end`。`agent.followup(msg)` 把訊息放進收件匣。
- **Session 紀錄**是只增的 JSONL,模型看到的歷史由它導出,所以分岔、續接、重播是同一份資料。
- **壓縮**:每步之前檢查壓力,先修剪工具結果,再用摘要取代紀錄的一段。
- **沒有內建長期記憶,也沒有「頻道」概念**。QQ、Discord、Bilibili 的橋全是外掛,用 `sessionController` 驅動 session。
- **外掛**:一個 npm 套件帶一份 patch 檔;profile 是一串有順序的 bundle;安裝來源可以是 npm、GitHub 或 tarball 網址。官方的 `SAFETY.md` 明說沒有稽核過,外掛能執行任意程式。

## 2. OpenClaw 和 Hermes Agent

**OpenClaw** [碼 / 文]:

- **Gateway**:一個常駐行程擁有所有平台連線和狀態;客戶端有角色(操作者 / 節點)和範圍;送出類的請求帶冪等鍵。
- **Channel 是外掛**:擁有設定、安全、配對、session 文法、送出。核心擁有唯一的 `message` 工具、路由和分派。
- **Session 鍵**:`agent:<id>:<channel>:group:<id>`,討論串再加一段;私訊的範圍可設(共用主 session、每人、每平台每人);`identityLinks` 把一個人在各平台的身分連起來。
- **旁聽**:沒被點名的群組訊息是安靜的脈絡,只有呼叫 `message` 工具才會出聲。群組的動靜以合併過的通知進主 session。私人記憶只在私人 session 載入。
- **工作區檔案**:規則、人設、身分、使用者、記憶各一份 Markdown;每日筆記按需搜尋;壓縮前先安靜地把值得留的寫進記憶。
- **主動**:改成一般的排程工作,可以用活躍時段、只在閒置、空則跳過、先跑一支不叫模型的腳本來擋,結果可以是安靜的 `NO_REPLY`。
- **節點配對分兩層**:先核可裝置(簽挑戰、拿裝置 token),再另外核可它宣告的指令範圍。一行指令加入,代碼 10 分鐘、只能用一次。遠端存取用 Tailscale Serve 或 SSH 隧道,gateway 綁 loopback。
- **上手**:`onboard` → 安裝成服務 → `dashboard` → `channels add` → `pairing approve`;修復用 `doctor --fix`、`status --deep`、`security audit`。

**Hermes Agent** [碼 / 文]:

- 「提示詞快取是神聖的」:CI 有快照測試,預設提示詞或工具清單一變就失敗。系統提示詞三層(穩定 / 脈絡 / 易變),記憶檔每個 session 凍結一份。
- 平台轉接器只要 `connect`、`disconnect`、`send`,其他(編輯、輸入中、核可提示)是選配。
- **學習迴圈**:agent 自己寫技能;一個背景審查者決定存什麼;久沒用的技能 14 天變舊、30 天封存。
- **排程**每 60 秒一拍,每個工作一個新的 agent,支援不叫模型的腳本工作、`[SILENT]` 標記、每個工作指定模型和思考量。
- **委派**最多 10 個子代理,結果可以要求符合 JSON schema。
- 終端機後端有本機、Docker、SSH、雲端沙箱。它沒有節點配對。

## 3. AI VTuber:AIRI、Neuro Game SDK、Open-LLM-VTuber

**Project AIRI**(v0.15.4)[碼]:

- `server-runtime` 只做認證、路由、健康,**不是大腦**;LLM 迴圈在 stage app 裡;Discord 和 Minecraft 是匯流排上的同儕。
- 信封帶伺服器蓋章的來源和路由(廣播 / 單一消費者 / 消費者群組)。事件有模組宣告、登記同步、健康、設定、輸入、輸出、可就地取代的脈絡通道、通知和指令。
- 能力只是一串字串,型別化的契約層還沒做完。記憶套件是空殼,Bilibili 外掛是 `WIP`。
- Minecraft:感知(規則)→ 反射(狀態機,可抑制)→ 意識(模型寫 JS 在沙箱跑)→ 動作(佇列 5、schema 驗證)。它的 README 說 Mineflayer 那條路要淘汰,改往 Fabric mod,和我們同方向。技能是手寫的,沒有學到的技能庫。
- 表情用串流裡的行內標記,在那一段聲音播出時觸發;提示詞列出目前模型確切的表情名稱。

**Neuro Game SDK** [文]:一條 JSON WebSocket:`startup`、`context{silent}`、註冊 / 取消動作(名稱、說明、JSON schema 子集)、`actions/force`(狀態、問題、暫時脈絡、四級優先)、`action/result`(約 20 秒逾時)、說話開始 / 結束。另有一條選配的語音通道(48 kHz、依說話者分流)。README 明說它是給回合制遊戲的,高 APM 的遊戲只該讓她下高階指令。遊戲用環境變數指定伺服器位址,所以第三方實作伺服器是預期用法。

**Neuro 本人**:可靠的只有 SDK 文件和少數訪談。模型、參數量、聲音引擎、記憶、主動和選聊天室訊息的做法,都沒有第一手來源 [二手]。

**Open-LLM-VTuber** [碼]:agent / ASR / TTS / VAD 各一個小的抽象類加工廠。被打斷時前端回報實際聽到的文字,記憶只記「聽到的部分…」加一個被打斷的標記,這是讀到最好的打斷做法。

**其他** [碼]:Mindcraft(每 tick 的反射模式加打斷清單;模型寫的程式存檔但不重用)。Voyager(唯一把驗證成功的程式加描述存進向量庫的)。kimjammer/Neuro(每個模組回傳一段帶優先級的提示詞;沒人說話才出聲)。Ikaros 的 AI-Vtuber(帶型別和優先級的輸出佇列、各類訊息的遺忘窗、佇列上限、去重,是讀到最完整的直播聊天室處理)。blivedm(禮物、SC、艦長都是帶金額的型別化事件)。開源的翻唱工具都是整批執行,沒有佇列。

## 4. 中文社群的陪伴 bot

**astrbot_plugin_private_companion**(v7.1.18,你貼的那個)[碼]:約 1,900 個 Python 檔,對象是 QQ 和微信。**沒有好感度數字**;作者的立場是「像人」來自「像人一樣過日子」,所以主動訊息來自她的作息、睡眠、天氣,不是計時器。

- 關係:每人一份 3,000 字的文字檔(稱呼、關係、互動方式);`RelationshipMemory` 記角色對人的主觀看法,必須有來源,有提出 → 審過 → 採用 → 撤回的狀態;紀念日只在使用者自己說過的話支持時才抽出。騷擾會累積,先冷卻 600 秒,再自動封鎖 168 小時。
- 情緒:喜怒哀懼四軸,各自往基準衰減。模型寫新值,但程式拒絕單輪變動超過上限的軸。
- 忙碌:她的行事曆說她在忙時,回覆延後(最多 900 秒),不會丟。
- **主動訊息是讀到最完整的設計**:每 5 分鐘一個機會窗 → 用雜湊當種子抽一個「念頭」(可重播)→ 15 種目的輪流(同時開五種會產生幾乎一樣的呼叫)→ 24 小時活躍曲線 → 每日額度(已送達和未回的都算)→ 沒回就把間隔 ×2.2 → 人設審查 → 送出前檢查有沒有捏造習慣(「你總是…」)→ 送達結果不明的不重送。
- 回覆:私訊等 1.5–4 秒合併;純晚安、純謝謝直接不叫模型;每回合的事實放在一個不落地的區塊以保住快取;一個小分類器先決定動作(回、等、不說、插話、反問)。
- 群組:只有明確的提及才算叫她;每行都帶說話者 id;群組和私訊的可見性有牆,在群裡問完 30 分鐘內私訊會有一次接續提示。

**AstrBot**(v4.29.4)[碼]:平台轉接器用裝飾器登記(18 個內建);訊息是元件清單;session 是 `platform_id:type:session_id`;一條九段的處理管線;外掛有 LLM 請求前後、工具呼叫、送出後的 hook,也能自己提供面板頁。內建的群聊主動回覆只是擲硬幣,聰明的行為全在外掛。沒有跨平台的身分合併。

## 5. 互動、經濟、抽卡、關係

這一節多數數字是 **[背景]**:Mudae 和 Karuta 的 wiki 讀不到,要用之前請在遊戲裡核對。讀到原始頁面的只有 Dank Memer 的通膨文章和《戀與深空》的回憶頁。

- **卡片 bot**(Mudae、Karuta、Sofi)[背景]:見 §0 第 7 點。
- **Dank Memer 的通膨教訓** [文]:一年裡使用者增加 96%,貨幣增加 3,655%。物品價值不要綁市價;任何可能讓總量翻倍的來源都要有上限;去處要隨餘額成長。
- **《戀與深空》** [文]:一張回憶卡同時是一個場面、一個戰力道具、一個好感來源。
- **Talkie** [背景]:從聊天時刻產生卡片,是「時刻卡」最接近的先例;有爭議的是它的課金,我們沒有真錢所以只留紀念品的部分。
- **Replika** [背景]:等級只量時間、不解鎖任何東西,使用者抱怨的正是這個。Nomi 和 Kindroid 贏在把記憶秀回給使用者看。
- **不讓數值變成農場** [背景 / 推論]:一次模型評估回傳變動,程式限制;每日上限;負面約三倍;羈絆衰減到「已達成的里程碑」為止;每晚對每個人反思一次;分級公開、確切數字只在管理面板;不做好感度排行榜。
- **生圖** [二手]:角色一致性用角色 LoRA(15–30 張)加參考圖編輯。FLUX.1 Kontext 量化後能在 12 GB 跑,但 dev 權重是非商用授權;Qwen-Image-Edit 據報要約 20 GB。單顯卡要排隊、一次一張、每人額度、先低解析度。這幾項都要實測。

## 6. 多台電腦

- **監管** [文]:process-compose 有存活和就緒探測、退避重啟、相依條件、日誌輪替、TUI 和 REST API,有 Windows 版;但 Windows 是它最少測的路(預設 shell 是 `cmd`、不支援 PTY)。Windows 服務包裝(NSSM、WinSW、Servy)跑在 session 0,帶不動 OBS 和 VTube Studio [推論]。Docker Compose 在 Windows 要 WSL2,留給 Linux 和沙箱。Nomad 和 k3s 對三四台電腦太重。
- **連線** [文]:自己的電腦用 Tailscale(帶 tag 的金鑰加入、grants 限制埠)。別人的電腦用對外撥出的連線:OpenClaw 節點、GitHub runner、Portainer edge agent 都是這個形狀。NATS leaf node 可行但多一個服務。
- **安裝** [文]:uv 每個 worker 一個環境,`uv sync --frozen`;CUDA 的 torch 要在專案設定裡指定 index 和平台條件(`--torch-backend=auto` 只對 `uv pip` 有效)。Node 的單一執行檔載不了原生模組,先用 npm 套件加一支 bootstrap 腳本。
- **GPU** [文]:Ollama 用保活加壓力下驅逐;llama-swap 依請求換整個行程。停行程比行程內卸載可靠,這和我們 worker 把模型放在子行程的做法一致。

## 7. 不要照抄的事

- **OpenClaw** [二手,數字彼此不一致,引用前要對官方公告]:大量 gateway 直接暴露在網路上;技能市集出過惡意技能;文件自己承認掃描器繞得過、裝上的技能有 agent 的全部權限;預設寬鬆(沙箱關、配對節點可以執行任何指令)。
- **Hermes** [文 / 二手]:官方政策說對抗惡意模型的唯一邊界是作業系統;外掛、hook、技能都在行程內;把檔案放進 hooks 資料夾就會被執行;兩個行程共用一個家目錄會互相弄壞記憶;小模型會說「我記下了」卻沒呼叫工具。
- **大肥魚**:沒有額度的主動就是洗版;外掛要登入 cookie,有違反平台規則的風險;字幕和留言要當資料不當指令。
- **MaiBot**:見 §4 它踩過的坑。
